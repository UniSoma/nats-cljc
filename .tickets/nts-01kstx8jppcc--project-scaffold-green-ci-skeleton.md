## Description

Stand up the build, dependency, and CI foundation so an empty library compiles and tests green on all three platforms — the substrate every later slice builds on. No NATS behavior yet.

Deliver: `deps.edn` (JVM deps incl. `io.nats:jnats` + promesa), `shadow-cljs.edn` (CLJS build + test targets), `deps.cljs` declaring the npm dep `@nats-io/nats-core`, a `tools.build` build script, a GitHub Actions CI matrix running JVM / Node / browser-headless against a downloaded `nats-server` binary with the **websocket listener enabled** (`ws://`), and an Apache-2.0 `LICENSE`.

The Clojars coordinate `io.github.UniSoma/nats-cljc` goes in the build config as-is. The `io.github.<owner>` segment is case-sensitive and permanent once published — verify it matches the GitHub org login exactly before the first publish (not a blocker for scaffolding).

**Pinned versions (researched 2026-05-29):**
- `io.nats/jnats` — `2.25.3` (latest 2.x; no 3.x exists yet)
- `funcool/promesa` — `11.0.678` (latest stable; do not pin the 12.0.0-RC2 pre-release)
- `org.clojure/clojurescript` — `1.12.145` (the release that adds native `^:async`/`await`, required by ADR 0002; this is the floor — do not go below it)
- `thheller/shadow-cljs` — `3.4.11` (the Clojars dep and the `shadow-cljs` npm package both at 3.4.11; keep them in lockstep)
- `@nats-io/nats-core` — `3.3.1` (npm)
- `nats-server` — `v2.14.1` (downloaded in CI)

**Browser-headless harness:** shadow-cljs `:karma` target driving headless Chrome via `karma-chrome-launcher` (npm devDeps: `karma`, `karma-chrome-launcher`, `karma-cljs-test`). Real-browser execution is the faithful environment for the `wsconnect` WebSocket transport. On GitHub Actions `ubuntu-latest` Chrome is preinstalled, so `ChromeHeadless` runs with no extra provisioning. CI step: `shadow-cljs compile test && karma start --single-run`.

ADRs: 0001 (transports), 0002 (CLJS >= 1.12.145 for native await), 0003 (toolchain — jnats + @nats-io/nats-core via shadow-cljs), 0009 (Apache-2.0, coordinate, semver contract).
